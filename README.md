# Expense Tracker
A simple browser-based expense tracker built with HTML, CSS, and JavaScript.
The application allows users to add recurring expenses, calculate their total expenses, select and remove individual expenses, and save expense data between browser sessions using localStorage.
## Features
- Add an expense with a name and amount
- Automatically calculate total expenses
- Prevent duplicate expense names
- Select individual expenses using checkboxes
- Delete selected expenses
- Clear all expenses
- Save expenses using browser localStorage
- Restore saved expenses when the page reloads
## Built With
- HTML
- CSS
- JavaScript
- Browser DOM API
- localStorage
